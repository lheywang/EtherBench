# Network

The network section is a vast part of the EtherBench project, and, it's name came from that : Ether, for Ethernet.
Therefore, it's not surprising to see most of the feature to be available over network.

There's a lot of services that are exposed.

!!! warning "Security"
    None of these services can be considered secure. It is the responsibility of the user to isolate the device properly on its network.
